# 健保碼快查（泌尿科）

健保署網頁版「醫療服務給付項目查詢」必須輸入和官方名稱幾乎一樣的字才查得到。這個小工具把泌尿科常用的處置、檢查、手術碼整理好，加上臨床慣用的英文縮寫和俗稱，打 `TURP`、`DJ`、`割包皮`、`放尿管` 也查得到。

## 功能

- **泌尿科精選 355 項**，分成 19 個子分類，並歸成 4 個大分類方便切換：
  - 🔪 **手術**（239）：腎、腎上腺、輸尿管、膀胱、尿道、陰莖/陰囊、睪丸/副睪、輸精管/精索、攝護腺、小兒泌尿、鼠蹊疝氣
  - 🩺 **處置**：泌尿處置、震波碎石（論病例計酬）、透析/移植相關
  - 🔍 **檢查**：內視鏡、尿路動力學、影像/超音波、放射介入
  - 🧪 **檢驗**：抽血、驗尿等檢驗項目
- **全部 5,899 項**健保給付項目也能查（切換「全部」）
- 聰明搜尋
  - 代碼、中文、英文縮寫都可以搜：`TURBT`、`PCNL`、`URSL`、`ESWL`、`HoLEP`、`cysto`、`VUDS`…
  - **打字就即時列出相符代碼**（下拉建議清單），不用按 Enter
  - 同義字互通：攝護腺＝前列腺、睪＝睾、廔＝瘻、部分＝部份、腹腔鏡＝lap…
  - 多個關鍵字用空白分開：`腹腔鏡 腎`、`lap nephrectomy`
  - 全形、半形都可以；不用打標點符號
  - 名稱找不到時，會改找「支付規範」的內文，再找不到就用模糊比對（例：`腎部切` → 腎部份切除術）
- 點代碼直接**複製**，☆ 加入**常用**清單
- 每個代碼都能展開看**支付規範**（適應症、限制、可否另加計材料費等）
- 部分代碼附上 **⚠ 申報提醒**（例如單側/雙側是否可加倍申報、依切除重量擇一申報等常見限制）。
  **這是整理者自行歸納的重點提醒，不是健保署逐字公告**，用來提醒查核而非直接依據，實際請以當年度支付標準通則及院內審查認定為準。
- **可離線使用**，手機可「加到主畫面」當 App 用

## 使用方式

**線上版（GitHub Pages）**：https://freshrogerchang-dev.github.io/health-insurance-charge-code/
手機用 Safari／Chrome 開啟後選「加入主畫面」，就能像 App 一樣使用，也支援離線。


- 直接用瀏覽器打開 `index.html` 就能使用（不需要網路、不需要安裝）
- 放到任何靜態網站空間（例如 GitHub Pages）後用手機開啟，選「加入主畫面」即可當 App 使用，並支援離線
- 整理好的清單另外輸出成：
  - [`docs/泌尿科健保碼整理.md`](docs/泌尿科健保碼整理.md)：依分類的表格
  - [`docs/urology-codes.csv`](docs/urology-codes.csv)：可用 Excel 開啟

## 資料來源與更新

資料取自衛生福利部「臺灣核心實作指引 (TW Core IG)」中的 CodeSystem「臺灣健保署醫療服務給付項目」（CC0 授權，npm 套件 `tw.gov.mohw.twcore`）。目前版本為 2024-11-29。

> 這份資料**不含支付點數**，也可能比健保署最新公告晚。申報前請以[健保署醫療服務給付項目查詢](https://info.nhi.gov.tw/INAE5000/INAE5001S01)為準。

更新資料：

```bash
python3 scripts/build_data.py --download
```

要新增分類、代碼、別名或申報提醒，編輯 `scripts/build_data.py` 裡的 `CATEGORIES`（含大分類）、`ALIASES`、`TIPS`、`SYNONYMS` 再重新執行即可。資料更新後，把 `sw.js` 裡的 `VERSION` 改一下，已安裝的手機才會抓新版。

```
docs/                             整理好的清單（自動產生）

```
